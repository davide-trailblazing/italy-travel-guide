# Italy travel guide

A simple, single-page travel guide to six places in Italy. For each place you get a food recommendation, the culture to see, and the beaches (spiagge) nearby. Each area is tagged with its signature food.

## Destinations
- Mainland: Rome, Florence, Venice
- Sicily: Ortigia, Taormina, Lipari

## Signature foods
- Rome: carbonara
- Florence: bistecca alla fiorentina
- Venice: cicchetti
- Sicily (Ortigia, Taormina, Lipari): ricotta
